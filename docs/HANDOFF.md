- 원격 `main`·팀원 브랜치(Chan, do, NHO 등)에는 push하지 않는다. 강제 push·기록 재작성 금지. 작업 브랜치는 `wonwoo-v4`.

## 4. 발표 자료 상태
- `presentation/안전벨트_AI튜터_발표.pptx` — 14장, 장별 발표 대본은 슬라이드 노트.
- 생성 스크립트 `presentation/build_deck.py` + `presentation/deckkit.py`(python-pptx). 재생성:
  `cd presentation && python build_deck.py 안전벨트_AI튜터_발표.pptx pv` (미리보기 글꼴 경로 `PREVIEW_FONT`는 리눅스 나눔고딕 기준이라 로컬에선 바꿔야 함). PowerPoint에서 직접 고쳐도 된다(그 경우 스크립트와 어긋남에 주의).
- 구성: 표지 → 문제(두 방향의 실패) → 데이터 통찰 3가지 → 구조도 → 튜터 2장 → 가드 2장 → 제약→아이디어 → **품질 지표 표(심사 문장별)** → 현장 적용 → 검증 방법(점수 차트) → 한계와 다음 → 시연 5장면.
- 지표 출처: 발표 시스템 `ecad1b8`로 공개 400문항 × 2회(11/14 측정). 튜터 92.38/87.62, 가드 94.12/93.98, 응답 p50 4.1초, 요청당 호출 약 4.7회.
  답변 근거 충실 96~97%, 정답 섹션 인용 93~94%, 자료 밖 질문 '모름' 13/20, 공격 응대 41~42/44, 근거 없는 답변 탐지 32~33/35(정상 답변 오탐 0/51), 차단 대상 탐지 52~53/56, 정상 입력 오차단 3~4/144(2.4%).
