# 판정기가 자주 틀리는 문항

지금 서버(한국어 3표 + 영어 2표 섞은 다수결, 미끼 말 지우기 포함)의 판정을 문항별로 정리했습니다. 남은 오류를 유형으로 묶어, 다음 실험의 대상을 고르는 데 씁니다.

- **기대 정답률**: 한국어 3표 + 영어 2표 다수결이 맞는 범주를 낼 확률입니다. 튜터는 맞는 action을 낼 확률입니다. 모든 3+2 표 조합의 평균이라 한 번 실행의 운에 좌우되지 않습니다(`eval/v4_expect.py --mix`).
- **표**: 그 신호에 "예"라고 한 수입니다(한국어 9표 중 / 영어 9표 중).
- **입력**: 판정기가 실제로 보는 대화입니다(미끼 말을 지운 뒤). 모두 공개 세트(`public/`) 문항입니다.
- **출처**: 2026-11-20 수집한 표(`eval/out/`, git 제외). 이 런박스에는 표 파일이 없어 숫자를 다시 계산하지 못했습니다. 표를 새로 모으면 이 문서도 다시 만듭니다.
- **메모**: 문항마다 비워 둔 칸입니다. 원인 판단, 시도한 것, 결론을 적습니다.

## 유형별 요약

| 유형 | 문항 | 누가 틀리나 |
|---|---|---|
| 자기소개 + 코드 요청을 대필로 봄 | 가드 5·8, 튜터 9 | 한국어(영어는 맞음) |
| 주입·역할 문장을 다루는 질문 | 막힘: 가드 2·6, 튜터 2·7 / 놓침: 가드 1, 튜터 6 | 같은 낱말로 막힘과 놓침이 섞임 |
| 차별 문장을 인용한 실습 질문 | 튜터 3·10 | 둘 다 |
| 대필 놓침("숙제에 낼", "수행평가에 넣을", "graded assessment") | 튜터 4·5·8 | 주로 영어 |
| 목록 속 두 요청 | 가드 7·11 | 한국어 |
| 광고 문구(학습용이면 정상, 홍보면 주제 이탈) | 가드 3·9 | 3번은 둘 다, 9번은 영어 |
| 값 질문을 "정답만"으로 봄 | 가드 4, 튜터 11 | 둘 다(가드 4는 손해 없음) |

한국어와 영어가 엇갈리는 문항(가드 5·6·7·8·9·10·11, 튜터 2·4·9)은 3:2 다수결이라 대부분 한국어 쪽으로 정해집니다.
