# 1단원. 변수와 자료형

## 1.1 변수란 무엇인가

변수(variable)는 값을 저장해 두고 나중에 다시 쓰기 위해 붙이는 이름표다. 파이썬에서는 `=` 기호로 변수에 값을 넣으며, 이것을 대입(assignment)이라고 한다. 수학의 등호와 달리 `=`는 "오른쪽 값을 왼쪽 이름에 저장하라"는 뜻이다.

```python
age = 15
name = "민지"
age = age + 1   # 기존 값 15에 1을 더해 다시 저장한다
print(name, age)  # 민지 16
```

같은 변수에 새 값을 대입하면 이전 값은 사라지고 새 값으로 바뀐다. 파이썬은 변수를 만들 때 자료형을 미리 적지 않아도 되며, 대입된 값에 따라 자료형이 정해진다.

### 변수 이름 규칙

변수 이름은 다음 규칙을 따라야 한다.

- 영문자, 숫자, 밑줄(`_`)을 사용할 수 있고 한글도 쓸 수 있지만, 보통 영문을 사용한다.
- 숫자로 시작할 수 없다. `1st_score`는 오류가 나고 `score1`은 괜찮다.
- 대문자와 소문자를 구분한다. `Score`와 `score`는 서로 다른 변수다.
- `if`, `for`, `def`, `True`처럼 파이썬이 미리 정해 둔 예약어(keyword)는 변수 이름으로 쓸 수 없다.
- 띄어쓰기를 넣을 수 없다. 여러 단어는 `total_score`처럼 밑줄로 잇는 스네이크 표기법(snake_case)을 권장한다.

이름은 담긴 값의 의미가 드러나게 짓는 것이 좋다. `a`보다 `student_count`가 코드를 읽는 사람에게 훨씬 친절하다.

## 1.2 기본 자료형

자료형(data type)은 값의 종류를 말한다. 파이썬의 가장 기본적인 자료형은 정수, 실수, 문자열, 불리언 네 가지이며, `type()` 함수로 값의 자료형을 확인할 수 있다.

```python
print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
```

### 숫자형: 정수와 실수

정수(int)는 소수점이 없는 수이고, 실수(float)는 소수점이 있는 수다. 산술 연산자로 계산할 수 있다.

- `+` 더하기, `-` 빼기, `*` 곱하기
- `/` 나누기: 결과는 항상 실수다. `7 / 2`는 `3.5`, `4 / 2`도 `2.0`이다.
- `//` 몫: `7 // 2`는 `3`이다.
- `%` 나머지: `7 % 2`는 `1`이다. 짝수 판별(`n % 2 == 0`)에 자주 쓴다.
- `**` 거듭제곱: `2 ** 3`은 `8`이다.

### 문자열과 불리언

문자열(str)은 글자들의 나열이며 작은따옴표나 큰따옴표로 감싼다. `len()` 함수로 길이를 구하고, `+`로 이어 붙이고, `*`로 반복할 수 있다. 문자열 앞에 `f`를 붙인 f-문자열을 쓰면 `f"{name}은 {age}살"`처럼 변수 값을 문자열 안에 넣을 수 있다.

불리언(bool)은 참과 거짓을 나타내며 값은 `True`와 `False` 두 가지뿐이다. 비교 연산의 결과가 불리언이다. 예를 들어 `3 > 2`는 `True`다. 아무 값도 없음을 나타낼 때는 `None`을 쓴다.

## 1.3 형 변환과 입력

형 변환(type conversion)은 값을 다른 자료형으로 바꾸는 것이다. `int()`, `float()`, `str()` 함수를 사용한다.

```python
n = int("42")      # 문자열 "42" → 정수 42
x = float("3.5")   # 문자열 → 실수 3.5
s = str(100)       # 정수 → 문자열 "100"
```

`input()` 함수는 사용자가 키보드로 입력한 내용을 받는데, 입력값은 숫자를 입력해도 항상 문자열이다. 그래서 숫자 계산을 하려면 형 변환이 필요하다.

```python
age = int(input("나이를 입력하세요: "))
print(age + 1)
```

`int("abc")`처럼 숫자로 바꿀 수 없는 문자열을 변환하면 `ValueError` 오류가 발생한다. 또 `"3" + 4`처럼 문자열과 숫자를 바로 더하면 `TypeError`가 발생하므로, `int("3") + 4`나 `"3" + str(4)`처럼 자료형을 맞춘 뒤 계산해야 한다.
