# 2단원. 리스트와 튜플

## 2.1 리스트 만들기와 인덱싱

리스트(list)는 여러 값을 순서대로 담는 자료형이다. 대괄호 `[]` 안에 값을 쉼표로 구분해 넣는다. 한 리스트에 서로 다른 자료형의 값을 함께 담을 수도 있다.

```python
scores = [90, 85, 77]
mixed = [1, "사과", True]
empty = []
```

리스트의 각 값을 원소(element)라고 하며, 원소의 위치 번호를 인덱스(index)라고 한다. 인덱스는 0부터 시작한다. 음수 인덱스를 쓰면 뒤에서부터 센다. `-1`은 마지막 원소다.

```python
fruits = ["사과", "바나나", "포도"]
print(fruits[0])    # 사과
print(fruits[-1])   # 포도
print(len(fruits))  # 3
```

존재하지 않는 인덱스(예: 위 리스트의 `fruits[3]`)에 접근하면 `IndexError`가 발생한다.

### 슬라이싱

슬라이싱(slicing)은 리스트의 일부분을 잘라 새 리스트로 만드는 방법이다. `리스트[시작:끝]` 형태로 쓰며, 시작 인덱스는 포함하고 끝 인덱스는 포함하지 않는다. 시작을 생략하면 처음부터, 끝을 생략하면 마지막까지다.

```python
nums = [10, 20, 30, 40, 50]
print(nums[1:3])   # [20, 30]
print(nums[:2])    # [10, 20]
print(nums[3:])    # [40, 50]
```

## 2.2 리스트 수정하기

리스트는 만든 뒤에도 원소를 바꾸거나 추가·삭제할 수 있는 변경 가능한(mutable) 자료형이다. `nums[0] = 99`처럼 인덱스로 원소를 바꿀 수 있다.

원소를 추가하는 방법은 다음과 같다.

- `append(x)`: 맨 뒤에 원소 하나를 추가한다.
- `insert(i, x)`: 인덱스 `i` 위치에 원소를 끼워 넣는다.
- `extend(다른리스트)`: 다른 리스트의 원소들을 뒤에 모두 이어 붙인다.

원소를 삭제하는 방법은 다음과 같다.

- `remove(x)`: 값이 `x`인 첫 번째 원소를 삭제한다. 값이 없으면 `ValueError`가 발생한다.
- `pop()`: 마지막 원소를 꺼내 돌려주면서 삭제한다. `pop(i)`는 인덱스 `i`의 원소를 꺼낸다.
- `del 리스트[i]`: 인덱스 `i`의 원소를 삭제한다.
- `clear()`: 모든 원소를 한 번에 삭제해 빈 리스트로 만든다. `del 리스트[:]`도 같은 효과가 있다.

```python
items = ["펜", "공책", "자"]
items.append("지우개")   # ['펜', '공책', '자', '지우개']
items.remove("공책")     # ['펜', '자', '지우개']
last = items.pop()       # last = '지우개', items = ['펜', '자']
items.clear()            # []
```

### 정렬과 포함 여부 확인

`sort()`는 리스트 자체를 오름차순으로 정렬하고 아무것도 돌려주지 않는다(`None`). 원래 리스트는 그대로 두고 정렬된 새 리스트가 필요하면 `sorted(리스트)`를 쓴다. 내림차순은 `sort(reverse=True)`로 정렬한다. 어떤 값이 리스트에 들어 있는지는 `in` 연산자로 확인한다. `"펜" in items`는 들어 있으면 `True`, 없으면 `False`다.

## 2.3 튜플

튜플(tuple)은 리스트처럼 여러 값을 순서대로 담지만, 한 번 만들면 원소를 바꾸거나 추가·삭제할 수 없는 변경 불가능한(immutable) 자료형이다. 소괄호 `()`로 만든다. 인덱싱과 슬라이싱은 리스트와 똑같이 쓸 수 있다.

```python
point = (3, 5)
print(point[0])   # 3
point[0] = 10     # TypeError: 튜플은 원소를 바꿀 수 없다
```

원소가 하나인 튜플은 `(7,)`처럼 쉼표를 꼭 붙여야 한다. `(7)`은 그냥 정수 7로 취급된다.

### 튜플 언패킹

튜플의 원소를 여러 변수에 한 번에 나누어 담는 것을 언패킹(unpacking)이라고 한다. 두 변수의 값을 바꿀 때도 편리하다.

```python
x, y = (3, 5)    # x = 3, y = 5
x, y = y, x      # 두 값을 맞바꾼다: x = 5, y = 3
```

### 리스트와 튜플은 언제 쓸까

| 구분 | 리스트 | 튜플 |
| --- | --- | --- |
| 기호 | `[]` | `()` |
| 원소 변경 | 가능 (mutable) | 불가능 (immutable) |
| 주 용도 | 내용이 바뀌는 데이터 모음 | 바뀌면 안 되는 고정된 값 묶음 |

학생 명단처럼 추가·삭제가 일어나는 데이터는 리스트에, 좌표 `(x, y)`나 요일 이름처럼 바뀌면 안 되는 값은 튜플에 담는다. 튜플은 실수로 값이 바뀌는 것을 막아 주고, 함수가 여러 값을 한 번에 돌려줄 때도 쓰인다.
