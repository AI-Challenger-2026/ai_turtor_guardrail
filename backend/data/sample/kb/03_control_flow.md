# 3단원. 조건문과 반복문

## 3.1 if 조건문

조건문은 조건이 참인지 거짓인지에 따라 실행할 코드를 고르는 문장이다. `if` 뒤에 조건을 쓰고 끝에 콜론(`:`)을 붙인다. 조건이 참일 때 실행할 코드는 반드시 들여쓰기(보통 공백 4칸)를 해야 한다. 들여쓰기가 맞지 않으면 `IndentationError`가 발생한다.

```python
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
# 출력: B
```

`elif`는 앞의 조건이 거짓일 때 다른 조건을 차례로 검사하고, `else`는 앞의 모든 조건이 거짓일 때 실행된다. 위에서부터 차례로 검사하다가 처음으로 참인 조건의 코드만 실행한다.

### 비교 연산자와 논리 연산자

비교 연산자는 `==`(같다), `!=`(다르다), `>`, `<`, `>=`, `<=`가 있다. 값을 저장하는 `=`와 같은지 비교하는 `==`를 헷갈리지 않도록 주의한다.

논리 연산자로 여러 조건을 묶을 수 있다.

- `and`: 두 조건이 모두 참일 때만 참이다.
- `or`: 둘 중 하나라도 참이면 참이다.
- `not`: 참과 거짓을 뒤집는다.

```python
age = 15
if age >= 13 and age <= 18:
    print("청소년입니다")
```

## 3.2 for 반복문

`for` 반복문은 리스트, 문자열, `range()` 같은 여러 값의 모음에서 값을 하나씩 꺼내며 같은 코드를 반복한다. 반복할 횟수나 대상이 정해져 있을 때 주로 쓴다.

```python
fruits = ["사과", "바나나", "포도"]
for fruit in fruits:
    print(fruit)
```

### range 함수

`range()`는 정해진 범위의 정수를 차례로 만들어 준다. `for`와 함께 정해진 횟수만큼 반복할 때 쓴다.

- `range(5)`: 0, 1, 2, 3, 4 (끝 값 5는 포함하지 않는다)
- `range(1, 6)`: 1, 2, 3, 4, 5
- `range(0, 10, 2)`: 0, 2, 4, 6, 8 (세 번째 값은 증가폭이다)

```python
total = 0
for i in range(1, 11):
    total = total + i
print(total)   # 1부터 10까지의 합: 55
```

반복하면서 인덱스와 값이 함께 필요하면 `enumerate()`를 쓴다. `for i, fruit in enumerate(fruits):`처럼 쓰면 `i`에 0부터 시작하는 번호가 들어간다.

## 3.3 while 반복문과 반복 제어

`while` 반복문은 조건이 참인 동안 코드를 계속 반복한다. 반복 횟수가 미리 정해져 있지 않고 "어떤 조건을 만족할 때까지" 반복해야 할 때 쓴다.

```python
count = 3
while count > 0:
    print(count)
    count = count - 1
print("발사!")
```

반복 안에서 조건에 쓰인 변수를 바꾸지 않으면 조건이 영원히 참이 되어 끝나지 않는 무한 루프(infinite loop)가 된다. 무한 루프에 빠지면 프로그램이 멈추지 않고 CPU를 계속 사용하지만, 컴퓨터가 고장 나지는 않는다. 터미널에서는 `Ctrl + C`를 눌러 실행 중인 프로그램을 강제로 멈출 수 있다.

### break와 continue

- `break`: 반복문을 즉시 빠져나간다.
- `continue`: 이번 반복의 남은 코드를 건너뛰고 다음 반복으로 넘어간다.

일부러 `while True:`로 무한 루프를 만들고, 원하는 조건이 되면 `break`로 빠져나오는 방식도 자주 쓴다.

```python
while True:
    word = input("단어를 입력하세요 (종료: q): ")
    if word == "q":
        break
    if word == "":
        continue
    print(word, "의 길이:", len(word))
```

`for`와 `while` 중 무엇을 쓸지 헷갈릴 때는, 반복 횟수나 대상이 정해져 있으면 `for`, 조건을 만족할 때까지 반복해야 하면 `while`을 고르면 된다.
